Features

- **Inventory Management:** Easily add, update, and delete products. Track stock levels and receive notifications for low stock.
- **Billing System:** Generate and print invoices quickly. Support for multiple payment methods.
- **Customer Management:** Maintain an organized database of customers with contact information and purchase history.
- **Reporting:** Generate detailed reports on sales, inventory status, and customer activities.
- **User Authentication:** Secure login system for users with role-based access control.
